How to check the CBSE result

  1. Open cbseresults.nic.in or cbse.gov.in.
  2. Choose Class X (Secondary) or Class XII (Senior School).
  3. Enter roll number, school number, admit-card ID and date of birth as on the admit card.
  4. Save a screenshot. The digital marksheet on DigiLocker / UMANG is the valid copy until the original arrives.

DigiLocker: sign in with the mobile linked to Aadhaar, then Education → CBSE. UMANG: search “CBSE” and use the same credentials. Helpline: 1800-11-8002 (CBSE).

Collect papers from school

  • Original CBSE marksheet and passing certificate — Academic Office, Gate 2, when CBSE delivers the lot (usually 4–6 weeks after declaration).
  • Migration certificate (Class XII) and character certificate — same desk, parent ID required.
  • School does not courier originals. Duplicate copies: written application + 7 working days.
  • Compartment / improvement forms are issued only after the student meets the Exam Cell with the marksheet.

If a paper is marked ABS / N.E. / Fail

Meet the class teacher within 3 working days. Compartment dates follow the CBSE circular, not this page. We do not discuss another child’s marks on the phone.
